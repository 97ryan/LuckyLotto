# Contributing

Contributions are welcome under GPL-3.0-or-later. Open an issue describing a proposed rule or model change, cite an official current source, and include a small reproducible probability example.

Run `./gradlew testDebugUnitTest lintDebug assembleDebug` before submitting. Odds and optimization changes require independent expected values or brute-force comparisons, including budget and time boundaries. Never infer a dollar prize from a past draw, present a cached value as live, embed website credentials or silently omit a game from the coverage table.

Keep the UI accessible and uncluttered. Do not add ads, analytics or ticket-purchase flows. Never commit signing keys, private account data or local SDK paths.
